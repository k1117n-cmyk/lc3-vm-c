# Attribution

This LC-3 VM implementation was written while following and adapting ideas from:

- Justin Meiners and Ryan Pendleton, "Write your Own Virtual Machine"
- https://www.jmeiners.com/lc3-vm/
- https://github.com/justinmeiners/lc3-vm

The original tutorial describes a small LC-3 virtual machine implemented in C and provides assembled sample programs such as `2048.obj` and `rogue.obj`.

The sample `.obj` files are downloaded from the original tutorial supplies and are not committed to this repository.
