# Attribution

This LC-3 VM implementation was written while following and adapting ideas from:

- Justin Meiners and Ryan Pendleton, "Write your Own Virtual Machine"
- https://www.jmeiners.com/lc3-vm/
- https://github.com/justinmeiners/lc3-vm

The original tutorial describes a small LC-3 virtual machine implemented in C and provides assembled sample programs such as `2048.obj` and `rogue.obj`.

The lesson snapshots may include small `.obj` files when an article needs a reproducible local command. For example, `lessons/07-profile/programs/2048.obj` is copied from the original tutorial supplies:

- https://justinmeiners.github.io/lc3-vm/supplies/2048.obj

Other downloadable sample `.obj` files should stay out of the repository unless a specific lesson requires them.
